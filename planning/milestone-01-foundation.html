Milestone 1

Foundation

Create the Bun, SQLite, tag model, routing, rendering, and static asset base needed for every later workflow.

Required first AC-21 AC-22 AC-23

Goal

The app starts locally, initializes the SQLite database automatically, and renders a minimal home page without external services.

Deliverables

  • Initialize project files: package.json, lockfile, .gitignore, and script commands.
  • Create src\server.ts with Bun.serve() bound to 127.0.0.1.
  • Create src\db.ts for SQLite connection and migration execution.
  • Create src\schema.ts with journal_entries, todos, tag tables, indexes, and review_items view.
  • Create shared query, validation, date, HTML escaping, and layout helpers.
  • Create public\styles.css, public\app.js, and vendored HTMX asset path.
  • Render a minimal Day View shell at /.

Implementation Steps

  1. Create project scaffolding and scripts, including bun run dev and test command.
  2. Write date, HTML escaping, tag parsing, and validation unit tests first.
  3. Implement date, tag, and validation helpers until unit tests pass.
  4. Write schema/migration tests that prove tables and view exist after initialization.
  5. Implement database connection and migration runner.
  6. Write an integration test for home page rendering.
  7. Implement route dispatch, layout rendering, static asset serving, and home shell.

Verification Gate

  • bun run dev starts on 127.0.0.1.
  • Visiting / renders the Day View shell.
  • tracker.db is created and contains required tables and indexes.
  • Tag tables support multiple tags per journal entry and TODO.
  • No external network service is required.
  • Unit and integration tests for helper and initialization behavior pass.

Risks

RiskMitigation
Overbuilding framework abstractions.Keep route dispatch explicit until repetition appears.
UTC date drift.Use local date helper for all grouping dates from the start.
Schema changes become hard later.Centralize migration SQL and keep tests around schema initialization.
Tags get overbuilt.Use simple normalized tag text and join tables. Defer colors, aliases, and tag management screens.
