Milestone 5

Markdown and AI Export

Generate the same accomplishment document as Markdown for humans and structured JSON/JSONL for AI-assisted review prep.

AC-19 AC-20

Goal

The review page can copy Markdown, download a .md file, and export a date-range data bundle that an agent can read without scraping the database directly.

Export Contract

RouteParametersResponse
GET /review/export.mdfrom, to, optional sort=asc|desc, optional highlightsOnly=1text/markdown attachment or inline download response.
GET /review/export.jsonfrom, to, optional sort=asc|desc, optional highlightsOnly=1, optional tagStructured review bundle with items, tags, stats, and metadata.
GET /review/export.jsonlSame filters as JSON export.One review item per line for large-range agent ingestion.

  2. GREEN: implement Markdown formatter from the review model without database access.
  3. RED: unit tests for JSON and JSONL AI export shape, tag arrays, stats, and stable date-range metadata.
  4. GREEN: implement AI export formatters from the same review model.

Done Gate

  • Markdown export content matches the review page model.
  • JSON and JSONL exports include range metadata, stats, tags, and normalized review items.
  • AI-readable exports support date range, highlight, sort, and tag filters.
  • Highlights-only export excludes unstarred items.
  • Downloaded file has a useful filename based on date range.
  • Copy button uses navigator.clipboard.writeText when available.
  • Manual fallback allows selecting/copying the generated Markdown.
  • Output can be pasted into a performance review draft without extra formatting.
