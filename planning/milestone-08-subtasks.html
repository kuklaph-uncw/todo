Milestone 8

Subtasks and Ordering

Let a todo hold a nested checklist, and let the user set the order of todos and subtasks by hand.

ST-1..ST-12 TDD required

Goal

A todo can be broken into steps without becoming a project plan. The todo stays the unit of review evidence. Its subtasks are a checklist that helps get it done.

This milestone replaces two M6 exclusions: drag-and-drop, and the priority/newest sort for live todos.

Scope

Included

  • Subtasks nested to any depth under a todo.
  • Subtasks are checklist items: text and done/not done.
  • Marking a todo or subtask done checks everything under it.
  • Progress (3/5) on the todo's tag line, counting every level. Only todos with subtasks show it.
  • Clicking a todo's title (or Enter on it) opens and closes its subtasks.
  • Manual order for live todos and for subtasks.
  • Drag by a grip handle, plus hotkeys for moving, indenting and outdenting.
  • Today tray: expand, check off, quick-add. Todos page: everything.

Excluded

  • Priority, star, goals, tags or dates on subtasks.
  • Subtasks as review evidence.
  • Turning a todo into a subtask, or a subtask into a todo.
  • Auto-completing a parent when its last subtask is checked.
  • Reordering Done and Cancelled (they stay sorted by completion date).
  • Move up/down or indent buttons.

File Format

An indented task line under a todo is a subtask, as in Obsidian. An indented plain line is still a note on the todo. Each level is written with four more spaces. File order is display order, and new todos are written at the top.

- [ ] Set up Azure DevOps org ⏫ ➕ 2026-10-27 ^8wfwpd
    Notes stay as indented plain lines.
    - [x] Pick org name ^k3m9qa
    - [ ] Invite team ^p7r2wd
        - [ ] Get list from manager ^z4n8ce
  • Subtask IDs share the file's ID space with todos.
  • [x] or [X] is done. Any other mark reads as not done, and is written back as [ ] when the app rewrites the todo.
  • A hand-written subtask without an ID gets one on first read, changing only that line. A rewritten todo puts notes first, then subtasks.
  • #tags and [[links]] in subtask text are shown but don't count toward tags, goals or filters.
  • Existing files with notes only read the same as before.

Requirements

IDRequirement
ST-1User can add a subtask under a todo or under another subtask.
ST-2User can check and uncheck a subtask.
ST-3Marking a todo or subtask done checks every subtask under it. Reopening or unchecking changes nothing else.
ST-4User can edit a subtask's text and delete a subtask. Deleting removes everything under it, with a copy in the trash.
ST-5Deleting a todo trashes its subtasks with it.
ST-6A todo with subtasks shows done/total across every level on its tag line, on Today and Todos. Clicking its title opens the list.
ST-7Live status groups show todos in the user's order. Priority is a badge, not a sort key.
ST-8User can drag a todo within the live list, and a subtask anywhere among subtasks, by its grip handle.
ST-9Hotkeys on a focused row on the Todos page: Alt+↑/Alt+↓ move among siblings, Alt+→/Alt+← indent and outdent. Listed in the ? dialog.
ST-10Today tray: a todo's subtasks can be opened from its title, checked off and quick-added.
ST-11Search matches subtask text.
ST-12Review evidence, exports and day summaries are unchanged.

Open Check

Alt+← is Back in browsers. Electron has no such binding. Verify the app can prevent it in a browser during bun run dev. If it can't, use Alt+Shift with the arrows instead.
