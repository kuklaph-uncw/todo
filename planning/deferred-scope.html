Scope Control

Deferred Scope

These items are useful, but they should not block v1. The first release succeeds when daily capture, tags, TODO context, review, Markdown and AI-readable export, persistence, and backup documentation work.

v1.1 Candidate

The full /data utility page is still optional for v1.1. Date-range AI-readable export belongs to Milestone 5 because it directly supports review preparation.

Non-Goals to Enforce During Implementation

  • No multi-user support.
  • No authentication while bound to localhost.
  • No cloud sync.
  • No telemetry.
  • No rich attachments.
  • No advanced tag hierarchy, colors, aliases, or tag management page.
  • No project or OKR hierarchy.
  • No recurring TODOs.
  • No AI-generated summaries inside the app.
  • No framework migration unless Bun + server-rendered HTML proves insufficient.

Scope Change Rule

If a deferred item becomes necessary, add a new milestone page before implementation. Do not quietly fold it into an existing milestone.
