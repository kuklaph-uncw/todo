Milestone 6

TODO Manager

Add a full task list view after the daily journal, TODO context, review, and export workflows already work.

AC-13 TM-1..TM-8

Goal

The user can manage all active and historical TODOs from /todos with filters, search, detail edits, highlights, soft delete, and explicit completion clearing.

Layout reference: TODO Manager mockup.

Scope

Included

  • View all non-deleted TODOs.
  • Filter by status, tag, and priority.
  • Search task and notes.
  • Create, edit, highlight, and soft delete TODOs.
  • Explicitly clear completion metadata with confirmation.
  • Default sort by status group, priority, and most recently updated.

Excluded

  • Recurring TODOs.
  • Kanban board or drag-and-drop.
  • Tag hierarchy, tag colors, aliases, or tag management screens.
  • Project hierarchy.

Default Sort

Sort LayerOrder
Status groupIn Progress, Open, Blocked, Done, Cancelled.
PriorityHigh, Medium, Low, None.
Updated timeMost recently updated first.
