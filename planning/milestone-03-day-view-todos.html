Milestone 3

Day View TODO Panel

Add lightweight TODOs to the daily screen, with tags for organization and completion metadata treated as historical evidence.

AC-8 AC-9 AC-10 AC-11 AC-12

Goal

The Day View shows active work and completed TODOs for the selected date without letting TODOs dominate the journal-first workflow.

Layout reference: Day View TODO mockup.

Scope

Included

  • Quick add TODO from Day View.
  • Default status Open, optional tags, no priority.
  • Sections for In Progress, Open, Blocked, and Completed on selected date.
  • Status updates to Open, In Progress, Blocked, Done, and Cancelled.
  • Edit task, priority, tags, and notes from Day View.
  • Soft delete TODOs.
  • Day summary counts include completed TODOs and highlights.

Excluded

  • Full TODO filters and search. That belongs to Milestone 6.
  • Explicit completion metadata clearing. That belongs to Milestone 6.
  • Recurring TODOs.
  • Project hierarchy or OKRs.

Completion Metadata Rules

ActionExpected Metadata Behavior
Create TODO as Opencompleted_at and completed_on remain null.
First mark DoneSet completed_at to current UTC ISO timestamp and completed_on to current local date.
Reopen completed TODOPreserve completion metadata.
Re-close reopened TODOPreserve original completion metadata.
Mark CancelledDo not set completion metadata. Preserve existing metadata if already completed.
Soft deleteSet deleted_at; hide from normal views and review output.

Done Gate

  • User can add a TODO with only a task title.
  • Optional TODO tags can be added, edited, normalized, and displayed.
  • Open, In Progress, and Blocked items appear in the correct sections.
  • Done TODOs appear under the date they were first completed.
  • Reopening and re-closing a TODO does not change original completion date.
  • Cancelled TODOs do not appear as completed accomplishments unless they already had completion metadata.
  • Day summary reflects journal entries, completed TODOs, highlights, and logged time.
