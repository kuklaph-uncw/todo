Decision Record

Keep SQLite. Add AI-readable exports.

SQLite should remain the source of truth. The app should expose review-range Markdown, JSON, and JSONL exports so an agent can summarize six months of work without scraping UI or connecting directly to the database.

recommended v1 export API deferred MCP deferred

Recommendation

Use SQLite for durability, querying, soft delete, TODO state, tag joins, and completion metadata. Add date-range exports in Milestone 5: Markdown for humans, JSON for structured agent context, and JSONL for long-range ingestion.

Options Considered

Option A

Markdown Files as Storage

Human-readable and easy for agents to consume, but brittle for TODO status transitions, completion metadata, tags, soft deletes, and date-range queries.

Verdict: Not recommended as the primary store.

Option B

SQLite Plus Exports

Best fit for local-first durability and review queries. Exports give agents clean input without compromising the app model.

Verdict: Recommended for v1.

Option C

Local API Endpoints

Useful if agents regularly call the running app, but it adds route surface, versioning decisions, and security questions before the need is proven.

Verdict: Defer beyond export endpoints.

Option D

MCP Server

Powerful for direct tool-style agent access, but premature until the schema and export format stabilize through real use.

Verdict: Future integration.

AI Export Principles

  • Exports are date-range scoped by default.
  • Exports include journal entries and completed TODOs from the same review model as the UI.
  • Exports include tags, highlight flags, priority, time spent, completion date, and source type.
  • Exports exclude soft-deleted records.
  • Exports include metadata: range, generated timestamp, app version if available, and filters used.
  • Exports are deterministic so two identical range requests produce equivalent content except generated timestamp.

Why Not Direct Database Access?

Agents can read SQLite when given file access, but that couples review workflows to internal schema details. Export routes preserve the database as an implementation detail and give agents a stable contract built for summarization.
