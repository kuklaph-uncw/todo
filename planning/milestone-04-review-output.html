Milestone 4

Review Output

Turn stored journal entries and completed TODOs into a readable accomplishment document grouped by date, with tags available for filtering and summarizing.

AC-14 AC-15 AC-16 AC-17 AC-18

Goal

The user can select a date range and see a clean accomplishment report with summary counts, highlights, journal entries, and completed TODOs.

Layout reference: Review page mockup.

Review Page Order

  1. Date range controls with presets and custom start/end dates.
  2. Copy/export action area reserved for Milestone 5 behavior.
  3. Highlight summary.
  4. Generated accomplishment document grouped by date.
  5. Supporting stats and tag breakdown.

Date Range Presets

PresetRule
This WeekCurrent local week.
This MonthFirst day through last day of current local month, clamped to today if preferred by UI.
This QuarterCurrent local quarter.
Last 6 MonthsRolling six-month range ending today.
Year to DateJanuary 1 through today.
CustomUser-selected inclusive start and end dates.

Output Model

Item SourceDate FieldContent FieldIncluded When
Journal entryentry_datecontentEntry is not soft-deleted and date is in range.
Completed TODOcompleted_ontaskTODO has completion date, is not soft-deleted, and date is in range.

Tags are loaded with each review item and used for tag breakdown counts. Tag filtering is useful enough for v1 if it remains simple: one optional tag filter in the review controls.

Done Gate

  • Custom date range returns expected journal entries and completed TODOs.
  • Items are grouped by non-empty date only.
  • Highlights-only mode excludes unstarred journal entries and TODOs.
  • Optional tag filter limits review output to matching tagged entries and TODOs.
  • Oldest-first and newest-first ordering work.
  • Stats include journal count, completed TODO count, highlights, active logging days, time logged, and tag counts.
  • Review page reads like a document, not an analytics dashboard.
