Milestone 2

Day View Journal

Build the fast freeform daily logging workflow with optional tags before the app grows into task management.

AC-1 AC-2 AC-3 AC-4 AC-5 AC-6 AC-7

Goal

The user can open the home page, choose a date, add one or many journal entries, edit them, delete them, star them, and keep unsent draft text across reloads.

Layout reference: Day View mockups.

Scope

Included

  • GET /?date=YYYY-MM-DD with default today.
  • Today, previous day, next day, and date picker controls.
  • Textarea quick capture with optional tags and time details.
  • Multiline create: split non-empty trimmed lines.
  • Inline edit for content, tags, time spent, and highlight flag.
  • Soft delete and hidden deleted entries.
  • Draft storage in localStorage, scoped by selected date.

Excluded

  • Saving a wrapped paragraph as one entry.
  • Restore deleted entry UI.
  • Tag hierarchy, tag colors, aliases, or tag management screens.
  • TODO functionality, except reserved page space if needed.

Done Gate

  • A simple entry can be added from the Day View in under 10 seconds.
  • Three pasted lines create three entries in creation order.
  • Optional tags can be added, edited, normalized, and shown on entries.
  • Past dates can be selected and edited.
  • Empty entries and negative time values show inline errors.
  • Deleted entries do not appear in normal day views.
  • Draft text survives reload and clears only after a successful save.
